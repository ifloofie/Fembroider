# Stitch Studio — source (v0.10.0)

Embroidery digitizer and 3D stitch preview. Machines: Bernina Deco 330 (EXP+ on a memory card) and
Poolin EOC06 (DST). Text with 50 fonts and swoops, the full emoji table, imported SVG/bitmaps, Pride
colourways, stripes and dithered gradients, thread/needle/fabric-aware density, a PBR texture bake, and a
Windows desktop build.

Code licence: MIT (see `LICENSE`). Bundled fonts, emoji artwork and thread charts keep their own licences (below).

## Layout

    studio/                  the app and the stitch engine (plain JavaScript, no framework)
      src/engine.js          masks → islands → tatami / satin / outline chords, underlay, swoops, travel grids
      src/export.js          sewing order (left-to-right sweep), travel routing, EXP / INF v2 / JEF / DST / BMP writers, zip
      src/app_*.js           UI: core state + machines, threads, 3D scene, direction tool, tips, panels, export & bake
      src/index.html         page template and CSS
      src/assets.gen.js      generated: fonts, themes, thread charts, packed emoji (from build_assets.py)
      src/emoji.json         generated: full emoji table with SVGs (used by the tests)
      src/emoji.pack.json    generated: gzip-packed emoji for the app
      src/fonts.json         generated: font manifest
      build_assets.py        builds assets.gen.js and fonts.json from node_modules/@fontsource and the palettes
      tools/build_emoji.py   builds emoji.json / emoji.pack.json from Twemoji 17 + emojibase 17
      build.py               assembles dist/artifact.html, dist/test/index.html and ../desktop/app/
      test/                  engine tests (t_*.mjs), quality harness, headless UI test (ui.py)
      vendor/inkstitch-palettes   thread charts (GPL-3.0, with licence)
    desktop/                 Electron shell (main.js, preload.js), icons
    .github/workflows/       Windows installer build on GitHub Actions (Actions tab → Run workflow)
      app/                   generated by studio/build.py (only icon.png is kept in source)

## Build

Requirements: Node.js 20+, Python 3.10+.

    cd studio
    npm ci                      # fonts, three.js, @napi-rs/canvas (tests)
    python3 build_assets.py     # only after changing fonts, themes or thread charts
    python3 build.py            # → dist/artifact.html (single file), dist/test/, ../desktop/app/

The generated asset files are included, so `npm ci` + `python3 build.py` is enough.
To rebuild the emoji table, fetch Twemoji v17.0.3 (`assets/svg`) and `emojibase-data@17.0.0`, set
`TWEMOJI_SVG` / `EMOJIBASE_DATA` (or place them in `../vendor_src/`), then run `python3 tools/build_emoji.py`
followed by `python3 build_assets.py`.

Desktop (Windows installer):

    cd desktop
    npm ci
    npx electron-builder --win nsis --x64     # on Linux: WINEDEBUG=-all xvfb-run -a npx electron-builder ...

## Tests

    cd studio
    node test/t_export.mjs        # likewise t_bands, t_gradient, t_threads, t_effects, t_fonts, t_emoji, t_import
    node test/quality.mjs         # stitch-quality harness (coverage, show-through, crossings, edge angles)
    python3 test/ui.py            # headless browser run of the whole app (needs Playwright + Chromium)
