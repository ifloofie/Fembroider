# Fembroider: notes for developers

How the code is organised, how to build it and how to test it. For what Fembroider is and how to use it, see the [README](../README.md).

## In one paragraph

Fembroider is plain JavaScript with no framework. One stitch engine turns text, emoji and imported art into satin,
tatami and running-stitch "chords"; a sewing planner orders them and writes machine files (PES, JEF, EXP + INF, VP3,
XXX, DST, and the Bernina Deco 330's EXP+ card set) for 197 machines from 17 brands. The same page runs as a web app
and inside a sandboxed Electron shell for Windows. Projects are `.fembroider` files (gzip-compressed JSON with the
design and every imported picture); autosave and version history live in IndexedDB.

## Layout

    studio/                  the app and the stitch engine (plain JavaScript, no framework)
      src/engine.js          masks → islands → tatami / satin / outline chords, underlay, swoops, travel grids
                             line art: ink vs. paper, skeleton → Euler-routed running stitch, tone → hatching
                             per-area edits (spec.edits / order / merge): Lines, Outline, Satin, Flat fill, Skip
      src/export.js          sewing order (left-to-right sweep), travel routing, EXP / INF / JEF / DST / PES / VP3 / XXX / BMP writers, zip
      src/machines.js        machine catalogue: models, hoops, file format, trimming, speed (searchable from the top bar)
      src/app_*.js           UI: core state + palettes, threads, 3D scene, direction tool, tips, panels, pie menu, export & bake,
                             projects (save / open / autosave / versions), boot
      src/index.html         page template and CSS
      src/assets.gen.js      generated: fonts, themes, thread charts, packed emoji (from build_assets.py)
      src/emoji.json         generated: full emoji table with SVGs (used by the tests)
      src/emoji.pack.json    generated: gzip-packed emoji for the app
      src/fonts.json         generated: font manifest
      build_assets.py        builds assets.gen.js and fonts.json from node_modules/@fontsource and the palettes
      tools/build_emoji.py   builds emoji.json / emoji.pack.json from Twemoji 17 + emojibase 17
      build.py               assembles dist/artifact.html, dist/test/index.html and ../desktop/app/
      test/                  engine tests (t_*.mjs), quality harness, headless UI tests (ui.py, ui_pie.py)
      vendor/inkstitch-palettes   thread charts (GPL-3.0, with licence)
    desktop/                 Electron shell (main.js, preload.js), icons
    studio/assets/brand/     app icon sources (SVG) and renders
    .github/workflows/       Windows installer build on GitHub Actions (Actions tab → Run workflow)
      app/                   generated by studio/build.py (only icon.png is kept in source)

## Build

Requirements: Node.js 20+, Python 3.10+.

    cd studio
    npm ci                      # fonts, three.js, @napi-rs/canvas (tests)
    python3 build_assets.py     # only after changing fonts, themes or thread charts
    python3 build.py            # → dist/artifact.html (single file), dist/test/, ../desktop/app/

The generated asset files are included, so `npm ci` + `python3 build.py` is enough.
To rebuild the emoji table, fetch Twemoji v17.0.3 (`assets/svg`) and `emojibase-data@17.0.0`, set
`TWEMOJI_SVG` / `EMOJIBASE_DATA` (or place them in `../vendor_src/`), then run `python3 tools/build_emoji.py`
followed by `python3 build_assets.py`.

Desktop (Windows installer):

    cd desktop
    npm ci
    npx electron-builder --win nsis --x64     # on Linux: WINEDEBUG=-all xvfb-run -a npx electron-builder ...

Ready-built Windows installers are attached to the GitHub Releases (the 110 MB installer is too large to keep in
the repository itself).

## Tests

    cd studio
    node test/t_export.mjs        # likewise t_bands, t_gradient, t_threads, t_effects, t_fonts, t_emoji, t_import
    node test/t_formats.mjs && python3 test/check_formats.py   # every format read back with pyembroidery
    node test/stress.mjs fonts|emoji|images [start] [end]      # stress sweep: travel, jumps, stitch outliers (JSON lines)
    node test/trace_jumps.mjs <emoji code | font:Family:Text | img:path>   # every jump of one design, for debugging
    node test/t_lineart.mjs <image> [sizeMM] [crop] [key=value]       # line-art mode: metrics + source | stitches picture
    LINE=1 DIR=test/line_images node test/stress.mjs images           # line-art sweep (synthetic drawings are in the repo)
    node test/t_edits.mjs <image> [sizeMM]                     # per-area edits (Lines, Outline, skip, order, edge, merge) side by side

The image sweep reads test/stress_images/ (not in the repo: add your own public-domain paintings and clipart).
    node test/quality.mjs         # stitch-quality harness (coverage, show-through, crossings, edge angles)
    python3 test/ui.py            # headless browser run of the whole app (needs Playwright + Chromium)
    python3 test/ui_pie.py        # the click-a-shape pie menu, on test/stickers/sticker-strawberry.png
