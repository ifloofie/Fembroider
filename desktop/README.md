# Stitch Studio (desktop)

Windows desktop build of Stitch Studio, an embroidery digitizer and 3D stitch preview for the
Bernina Deco 330. Electron shell around the same page as the web version: one sandboxed window,
local files only. The renderer files in `app/` are generated by `../studio/build.py`.

## Build

    npm ci
    npx electron-builder --win nsis zip --x64

On Linux, Windows builds also need Wine (64- and 32-bit) and a virtual display:
`xvfb-run -a npx electron-builder --win nsis zip --x64`. A real Windows machine or the
GitHub Actions workflow in the repository root (`.github/workflows/windows.yml`, which builds `studio/` first) needs neither.

## What the app does and does not do

- Loads only files packaged inside it. Every network request is cancelled in the main
  process, and the page's Content-Security-Policy refuses network connections as well.
- The page has no Node.js access (`contextIsolation`, `sandbox`, no `nodeIntegration`).
- Denies all permission requests (camera, microphone, notifications, location, ...).
- Writes files only through two IPC calls exposed by `preload.js`: "Save" (a normal Save
  dialog; the file name and type are checked) and "Write to card or stick" (a folder dialog;
  only `NAME.EXP`, `.INF`, `.BMP` or `.DST` with 8-character names: the Deco 330 set goes into
  the card's `EmbF5` folder, a Poolin DST into the chosen folder; it asks before it creates the
  folder or replaces files). Both check that the request came from the app's own page.
- No auto-updater, no child processes, no registry writes beyond the installer's own
  uninstall entry, no admin rights (installer and app both run `asInvoker`).
- Electron fuses: RunAsNode, NODE_OPTIONS and inspector flags disabled; app code only
  from app.asar.

## Antivirus notes

- Not packed (no UPX), no self-extracting "portable" exe; the zip is a plain folder.
- Version info is filled in and consistent (name, company, description, original filename).
- Unsigned. Windows SmartScreen will warn "Windows protected your PC" until the build is
  code-signed and gains reputation. Options: Azure Trusted Signing, or SignPath (free for
  open-source projects). Signing hooks are stubbed in the workflow.
- If an engine flags a build, submit the file to Microsoft at
  https://www.microsoft.com/en-us/wdsi/filesubmission as a false positive.
